## ✨ 주요 기능

### 🤖 AI 기도문 생성
- OpenAI GPT-3.5 Turbo를 활용한 지능형 기도문 자동 생성
- 예배 종류에 맞는 맞춤형 기도문 제공
- 천천히 읽었을 때 약 5분 분량의 적절한 길이로 생성
- 자연스럽고 은혜로운 기도문 스타일

### 📝 기도문 작성 및 편집
- 직접 기도문을 작성할 수 있는 텍스트 입력 필드
- 9가지 예배 종류 중 선택 가능
- 특별예배는 사용자 지정 예배명 입력 가능

### 💾 로컬 저장
- SharedPreferences를 이용한 안전한 로컬 저장
- 인터넷 연결 없이도 저장된 기도문 확인 가능
- 데이터 마이그레이션 지원으로 앱 업데이트 시에도 데이터 보존

### 📋 기도문 관리
- 저장된 모든 기도문을 날짜순으로 목록 확인
- 기도문 상세 보기 (크게 보기)
- 불필요한 기도문 삭제 기능

### 🎨 사용자 친화적 UI/UX
- 직관적인 그리드 레이아웃의 예배 종류 선택
- 부드러운 네비게이션
- 명확한 에러 메시지 및 성공 피드백
- 한국 교회 문화에 맞춘 디자인

## 📖 앱 사용법

### 1. 기도문 작성하기

#### 1-1. 예배 종류 선택
- 앱 실행 시 메인 화면에 9개의 예배 종류가 그리드 형태로 표시됩니다
- 원하는 예배 종류를 탭하여 선택합니다
- 선택된 예배 종류는 초록색으로 강조 표시됩니다

#### 1-2. 특별예배 선택 시
- "특별예배"를 선택하면 예배명 입력 필드가 활성화됩니다
- 직접 예배명을 입력할 수 있습니다 (예: "추수감사절", "성탄절" 등)
- 새로고침 버튼(🔄)을 누르면 입력한 내용을 초기화할 수 있습니다

#### 1-3. 기도문 내용 입력
- 하단의 큰 텍스트 입력 필드에 기도문을 직접 작성합니다
- 여러 줄 입력이 가능합니다

### 2. AI로 기도문 생성하기

#### 2-1. AI 도움받기 기능 사용
1. 예배 종류를 먼저 선택합니다
2. "🙏 AI 도움받기" 버튼을 탭합니다
3. 인터넷 연결이 필요합니다 (OpenAI API 사용)
4. 생성 중에는 로딩 인디케이터가 표시됩니다
5. 약 10-30초 후 기도문이 자동으로 입력 필드에 채워집니다

#### 2-2. AI 생성 실패 시
- 네트워크 오류나 API 오류 시 안내 메시지가 표시됩니다
- "예 (Yes)" 버튼을 누르면 샘플 기도문을 사용할 수 있습니다
- 샘플 기도문은 기본적인 기도문 형식으로 제공됩니다

#### 2-3. 생성된 기도문 수정
- AI가 생성한 기도문은 그대로 사용하거나 수정할 수 있습니다
- 텍스트 입력 필드에서 자유롭게 편집 가능합니다

### 3. 저장된 기도문 보기

#### 3-1. 기도문 저장
1. 기도문 내용을 입력하거나 AI로 생성합니다
2. "저장하기" 버튼을 탭합니다
3. 저장 완료 메시지가 표시됩니다
4. 자동으로 "저장된 기도문" 화면으로 이동합니다

#### 3-2. 저장된 기도문 목록
- "내 기도문 보기" 버튼을 탭하거나 저장 후 자동 이동
- 각 기도문은 카드 형태로 표시됩니다
- 날짜와 예배 종류가 상단에 표시됩니다
- 기도문 내용은 2줄까지만 미리보기로 표시됩니다

### 4. 기도문 상세 보기

#### 4-1. 전체 내용 보기
- 저장된 기도문 목록에서 원하는 기도문 카드를 탭합니다
- 전체 화면으로 기도문 내용을 크게 볼 수 있습니다
- 날짜, 예배 종류, 기도문 전체 내용이 표시됩니다

#### 4-2. 화면 구성
- 상단: 날짜 (초록색 박스), 예배 종류 (초록색 텍스트)
- 하단: 기도문 전체 내용 (자동 줄바꿈, 읽기 편한 글꼴 크기)
- 뒤로 가기 버튼으로 목록으로 돌아갑니다

### 5. 기도문 삭제하기

#### 5-1. 삭제 방법
1. 저장된 기도문 목록 화면에서 각 카드의 우측 하단에 있는 삭제 아이콘(🗑️)을 탭합니다
2. 삭제 확인 대화상자가 나타납니다
3. "삭제" 버튼을 누르면 삭제되고, "취소" 버튼을 누르면 취소됩니다

#### 5-2. 삭제 후
- 삭제가 완료되면 목록에서 해당 기도문이 제거됩니다
- 삭제 완료 메시지가 표시됩니다

## 🎯 지원하는 예배 종류

앱에서 지원하는 9가지 예배 종류:

1. **주일예배** ☀️ - 매주 일요일 주일 예배
2. **금요예배** ⭐ - 금요 저녁 예배
3. **구역예배** 👥 - 소그룹 구역 예배
4. **새벽예배** 🌅 - 새벽 기도 예배
5. **심방예배** 🏠 - 가정 심방 예배
6. **수요예배** 💧 - 수요 저녁 예배
7. **가정예배** 🏡 - 가정에서 드리는 예배
8. **병원예배** ⛑️ - 병원이나 요양원 예배
9. **특별예배** 📅 - 특별한 날의 예배 (사용자 지정 가능)

## 🚀 설치 및 실행

### 사전 요구사항
- Flutter SDK 3.7.2 이상 설치
- Dart SDK 설치
- Android Studio / Xcode (모바일 빌드용)
- OpenAI API 키

### 설치 절차

#### 1. 프로젝트 클론 또는 다운로드
```bash
# 저장소가 있다면
git clone [repository-url]
cd repre_prayer_new
```

#### 2. 의존성 설치
```bash
flutter pub get
```

#### 3. 환경 변수 설정
프로젝트 루트에 `.env` 파일을 생성하고 다음 내용을 추가합니다:
```
OPENAI_API_KEY=your_openai_api_key_here
```

**⚠️ 중요**: `.env` 파일은 Git에 커밋하지 마세요. 실제 API 키를 노출하지 않도록 주의하세요.

#### 4. 앱 실행
```bash
# 개발 모드로 실행
flutter run

# 특정 디바이스에서 실행
flutter run -d [device-id]

# 릴리스 모드로 빌드 (Android)
flutter build apk --release

# 릴리스 모드로 빌드 (iOS)
flutter build ios --release
```

### Android 빌드 설정
- `android/app/key.properties` 파일에 서명 키 정보 설정 필요
- `android/app/build.gradle.kts`에서 서명 설정 확인
